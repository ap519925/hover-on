# hover-on

> **140+ professional hover effects organized by use case**

Turn your hover effects on! The most comprehensive, production-ready hover effects library for modern web development.

## ✨ Features

- 🎯 **140+ Effects** - Most comprehensive library available
- 📦 **Organized by Use Case** - Navigation, Buttons, Cards, Images, Text, Icons, Modern, Classic
- 🎨 **TypeScript Native** - Full type safety
- 🌐 **Framework Agnostic** - Works everywhere
- 🎭 **Zero Dependencies** - Lightweight
- 📱 **Responsive** - All devices
- ♿ **Accessible** - Respects prefers-reduced-motion

## 🚀 Quick Start
```bash
npm install hover-on
```
```javascript
import { Navigation, Buttons, Cards } from 'hover-on';

Navigation.underline.slide('nav a');
Buttons.sweep.radial('.btn');
Cards.transform.lift('.card');
```

## 📚 Categories

- **Navigation** (11) - Menu items, nav links
- **Buttons** (37) - CTAs, action buttons  
- **Cards** (10) - Product cards, content blocks
- **Images** (15) - Galleries, portfolios
- **Text** (13) - Headings, titles
- **Icons** (11) - Social media, UI icons
- **Modern** (20) - Advanced CSS
- **Classic** (25) - Traditional transforms

## 💡 Examples
```javascript
// E-commerce
Navigation.underline.slide('nav a');
Cards.transform.lift('.product-card');
Buttons.advanced.neon('.btn-cart');

// Portfolio
Images.gallery('.portfolio');
Text.glow.sparkle('h1');
Icons.basic.glow('.social');
```
