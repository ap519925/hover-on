Drupal Integration Guide

Easily integrate hover-on-lib into your Drupal site using the dedicated module (no coding required).

Step 1: Install the Module

Copy the hover_on directory to your site's modules folder:

web/modules/custom/hover_on/

Then enable the module:

drush en hover_on

Step 2: Configure Effects

Go to Configuration > User Interface > Hover On Effects Settings in your Drupal admin toolbar.

Add your rules using the simple format: Selector | Effect | Type | Color

Example Configuration

Paste this into the settings page to see immediate results:

# Apply underline to main menu links nav.primary-nav a | underline | slide | #4ecdc4 # Apply sweep effect to all buttons .button, .btn | background | left | #ff6b6b # Apply 3D lift to teaser cards .node--view-mode-teaser | transform3d | lift
